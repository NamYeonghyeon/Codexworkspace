# 상식 OX 퀴즈

한국어 상식 5문제를 하나씩 풀어 보는 반응형 웹 프로그램입니다. HTML, CSS, JavaScript를 저장소 최상위의 `index.html` 하나에 담았습니다. 외부 라이브러리, 외부 폰트, 서버, 데이터베이스를 사용하지 않습니다.

## 기능

- O / X 선택 후 즉시 정답 판정과 해설 표시
- 문항당 20점, 총 100점 및 맞힌 문제 수·정답률 표시
- 중복 답변 방지, 진행 상태와 현재 점수 표시
- 결과 화면에서 다시 시작 및 전체 정답·해설 복습
- PC·모바일 대응, 키보드 O / X 및 Enter 지원

## GitHub Pages 배포

1. `index.html`과 `.nojekyll`을 `main` 브랜치의 최상위 경로에 반영합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Source: Deploy from a branch**를 선택합니다.
3. **Branch: main**, **Folder: / (root)**를 선택하고 **Save**를 누릅니다.
4. Pages 배포 완료 후 설정 화면에 표시되는 사이트 주소로 접속합니다.

이 저장소의 기본 Pages 주소는 `https://namyeonghyeon.github.io/Codexworkspace/`입니다. 실제 배포 완료 여부는 저장소의 Pages 설정과 배포 상태로 확인해야 합니다.

비공개 저장소에서 GitHub Pages를 사용하려면 이를 지원하는 GitHub 요금제가 필요합니다. 해당 요금제가 없다면 소유자가 공개 저장소로 전환하거나 지원되는 요금제를 사용해야 합니다. **코드 저장소가 비공개여도 일반적인 Pages 사이트는 인터넷에 공개될 수 있습니다.**

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 퀴즈 화면, 스타일, 문제 데이터와 동작 전체 |
| `.nojekyll` | Jekyll 처리 없이 정적 파일 배포 |
| `.gitignore` | 개발 중 임시 파일 제외 |

## 수정 방법

`index.html`의 `questions` 배열에서 문제 문장(`text`), 분류(`category`), 정답(`answer`: `true`는 O, `false`는 X), 해설(`explanation`)을 바꿀 수 있습니다. 현재 화면은 5문제 구성에 맞춰져 있습니다.

외부 리소스나 네트워크 요청이 없으므로 페이지 로딩이 끝난 뒤에는 인터넷 연결 없이 모든 문제를 풀 수 있습니다. 오프라인 상태에서 주소를 새로 열거나 새로고침하는 기능은 포함하지 않습니다.

## 검증 결과

- Chromium 브라우저에서 가능한 32가지 답변 조합의 정답 판정, 해설, 0~100점 계산, 결과 화면, 복습, 재시작 확인
- 중복 답변 방지, 답변 전 다음 문제 이동 차단, 키보드 O / X / Enter 동작 확인
- 280 / 320 / 375 / 390 / 768 / 1280px 화면 너비에서 가로 넘침 없이 표시되는지 확인
- 최초 로딩 후 네트워크를 끊은 상태에서 전체 문제와 재시작 정상 동작 확인
- 외부 리소스 의존성 및 JavaScript 실행 오류 없음, JavaScript 문법 검사 통과
